# 🏗 Full Stack System Architecture (NexusHR)

```mermaid
flowchart TD
    Client["Client Browser\n(React 18 + Tailwind + TanStack Query)"]

    subgraph API_GATEWAY ["Security & Ingress Layer"]
        Security["Spring Security 6\n(JWT Provider + TOTP 2FA + RBAC)"]
        Filter["JwtAuthenticationFilter\n(Fail-Safe Redis Circuit Breaker)"]
    end

    subgraph CORE_BACKEND ["NexusHR Core Services (Spring Boot 3 + Virtual Threads)"]
        Controllers["REST Controllers & SSE Gateway"]
        Services["Domain Services\n(Auth, Attendance, Payroll, Leave)"]
        EventProducer["MessageProducerService\n(Fail-Open Correlation Publisher)"]
    end

    subgraph BROKER ["Asynchronous Message Broker"]
        RabbitMQ{{"RabbitMQ Event Exchanges\n(Emails, Audit Logs, Heavy Payroll)"}}
    end

    subgraph DATA_TIER ["Persistence & Distributed State"]
        Redis[("Redis Distributed Cache\n& Token Revocation (<1ms)")]
        MySQL[("MySQL Database\n(Flyway Schema Migrations)")]
        Cloudinary[("Cloudinary Secure Vault\n(Encrypted PDF Payslips & Docs)")]
    end

    subgraph AI_SERVICES ["AI & Vector Intelligence"]
        SpringAI["Spring AI (Google Gemini)"]
        Qdrant[("Qdrant Vector DB\n(Candidate Semantic Search)")]
    end

    Client <-->|HTTPS REST / SSE| Security
    Security --> Filter
    Filter --> Controllers
    Controllers --> Services
    Services <-->|Fast Caching & Circuit Breaker| Redis
    Services <-->|JPA / Hibernate Batching| MySQL
    Services -->|Async Pub/Sub| EventProducer
    EventProducer --> RabbitMQ
    Services <-->|Document Uploads| Cloudinary
    Services <-->|Semantic Match & GenAI| SpringAI
    SpringAI <--> Qdrant
